\# 🧠 IT Quiz Bot



A Telegram bot for testing IT knowledge through interactive quizzes.



The bot provides random questions, instant answer feedback, explanations, statistics and a simple user-friendly interface.



\## 🚀 Features



\- 🧠 Interactive IT quizzes

\- 🎲 Random questions

\- ✅ Instant answer checking

\- 💡 Explanations after each answer

\- 📊 Personal statistics

\- 🎯 Accuracy calculation

\- 🏆 Completed tests counter

\- 👤 Separate statistics for every Telegram user

\- 💾 SQLite database

\- 📱 Telegram inline buttons

\- ⚡ Fast asynchronous architecture with Aiogram



\## 🛠️ Technologies



\- Python 3

\- Aiogram 3

\- SQLite

\- python-dotenv

\- Telegram Bot API
